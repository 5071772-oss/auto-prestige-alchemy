# План: Улучшение отображения комплектации (Модальное окно)

Мы заменим текстовое поле комплектации в карточке на интерактивное модальное окно, которое будет открываться при клике на карточку или специальную кнопку. Это сделает интерфейс чище и позволит отобразить подробное описание автомобиля без перегрузки основной сетки.

## Что будет сделано

### 1. Интеграция компонентов Dialog
* Используем библиотеку `@radix-ui/react-dialog` (через существующие компоненты `ui/dialog`) для создания премиального модального окна.

### 2. Обновление CarCard
* Сделаем всю карточку (или её верхнюю часть с фото) кликабельной для открытия деталей.
* Вынесем подробную комплектацию и описание во всплывающее окно.

### 3. Дизайн модального окна
* **Шапка**: Название модели, год и статус.
* **Галерея**: Увеличенная карусель изображений.
* **Контент**: Четкое разделение на "Характеристики", "Комплектация" и "Описание".
* **CTA**: Кнопка бронирования внутри модального окна.

## Технические подробности

* **Файл**: `src/pages/Stock.tsx`.
* **Компоненты**: `Dialog`, `DialogContent`, `DialogHeader`, `DialogTitle`.
* **Стили**: Адаптация под темную премиальную тему с золотыми акцентами.
