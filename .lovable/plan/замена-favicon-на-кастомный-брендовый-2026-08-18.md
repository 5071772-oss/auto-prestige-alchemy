# Замена favicon на кастомный брендовый

## Что делаем
Заменим стандартный Lovable favicon на собственный, соответствующий премиальному стилю личного бренда Алексея Николаева.

## Шаги

1. **Сгенерировать favicon**
   - Создать изображение-монограмму в премиальном стиле: буква «Н» (или «АН») на тёмном/графитовом фоне с золотисто-серебристым акцентом.
   - Стиль: минималистичный, дорогой, вписывается в палитру сайта (чёрный, графит, белый, золото).

2. **Подготовить файл**
   - Сохранить сгенерированное изображение как `public/favicon.png`.
   - Привести к квадратному формату 64×64 px с сохранением пропорций (padding, не растяжение).

3. **Обновить `index.html`**
   - Добавить в `<head>`:
     ```html
     <link rel="icon" href="/favicon.png" type="image/png" />
     ```

4. **Удалить стандартный favicon**
   - Удалить `public/favicon.ico`, чтобы браузер не подтягивал старый файл по умолчанию.

5. **Проверить**
   - Убедиться, что в браузере на вкладке отображается новый favicon.
