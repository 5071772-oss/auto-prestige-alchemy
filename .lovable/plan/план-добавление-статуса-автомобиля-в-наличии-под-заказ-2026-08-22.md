# План: Добавление статуса автомобиля (В наличии / Под заказ)

Мы добавим возможность указывать статус автомобиля в Google Таблице и отображать его на сайте. Это позволит четко разделять машины, которые уже есть, и те, которые можно привезти под заказ.

## Что будет сделано

### 1. Подготовка Google Таблицы
* Добавим новый столбец **status** в таблицу «Автомобили в наличии».
* Для BMW X7 установим статус «В наличии», для Rolls-Royce — «Под заказ».

### 2. Обновление Edge Function
* Изменим функцию синхронизации `sync-google-sheets`, чтобы она считывала данные из нового столбца (индекс 20).
* Сопоставим эти данные с полем `status` в базе данных.

### 3. Обновление интерфейса (Frontend)
* Обновим компонент `CarCard` на странице «В наличии», чтобы он отображал реальный статус из базы данных вместо статичного текста.
* Добавим визуальный индикатор (бейдж) для статуса «Под заказ», чтобы он выделялся.

## Технические подробности

* **Колонка в таблице**: U (21-я колонка, индекс 20).
* **Поле в БД**: `cars.status` (уже существует в схеме).
* **Edge Function**: Обновление маппинга в `supabase/functions/sync-google-sheets/index.ts`.
* **CarCard**: Изменение строки «Статус» в `src/pages/Stock.tsx`.
